### ONSB
> 블록체인 기반 파일 공유 및 액세스 제어 서비스


<br/>

## 📝 프로젝트 소개

캡스톤디자인 수업 과제로 개발한 웹 서비스 입니다.


기존 파일 공유 서비스의 중앙 집중식 서버 시스템과 복잡한 절차를 개선하는 것을 목표로 했습니다.
ONSB는 IPFS와 블록체인 네트워크로 구성되어 웹의 형태로 제공됩니다. IPFS와 이더리움을 이용한 블록체인 네트워크로 서버의 중앙화를 제한하고
익명으로 서비스를 구동하여 보안을 높였으며, 권한 요청부터 파일 열람까지의 과정을 간소화했습니다.

<br/>

## 주요 기능

- **사용자 인증** - 파일 업로더는 아이디와 비밀번호로 로그인하며, 파일 열람자는 업로더의 아이디를 입렵해 공유 대상에 접근합니다.
- **파일 업로드** - 파일을 업로드하고 관리할 수 있습니다.
- **접근 권한 요청 및 승인** - 파일 열람자가 로그인 시 권한이 요청되며, 업로더가 요청을 확인하고 승인할 수 있습니다.
- **파일 열기** - 접근 권한을 승인받은 사용자는 공유된 파일을 열람할 수 있습니다.
